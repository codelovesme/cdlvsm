cdlvsm

one binary, every codelovesme CLI

A package manager and dispatcher for first-party command-line tools. It installs a tool under a versioned directory, keeps it up to date, and then transparently runs it — argv, stdio, exit codes, signals, all forwarded as if you'd run the real thing.

why cdlvsm

      
A thin layer that does its job

      

        No daemons, no registries of its own, no build tooling. One small Rust
        binary that shells out to curl and tar — and
        gets out of the way when your program actually runs.
      

    

    

      

        

          
        

        
Transparent dispatch

        
cdlvsm <package> <args…> execs the installed binary directly — argv, stdin/stdout/stderr, exit code, and signals all pass through untouched.

      

      

        

          
        

        
Versioned installs

        
Every release lives in its own directory under $PREFIX/share/cdlvsm/packages/<pkg>/<version>/, with a current symlink doing the routing.

      

      

        

          
        

        
Safe uninstall

        
uninstall removes a shim only if it's a symlink cdlvsm itself created. Your VS Code code binary is never touched.

      

      

        

          
        

        
Upgrades keep your flags

        
Each install records how it was done. upgrade reuses those exact settings — a --runtime --link install stays one.

      

      

        

          
        

        
Zero dependencies

        
No LLVM, no runtime to install. The whole crate has no external Rust deps — it just needs curl and tar on your PATH.

      

      

        

          
        

        
Pin what matters

        
CDLVSM_CODE_VERSION and friends pin a package's release; PREFIX moves the whole tree. Reproducible installs, no lockfile required.

      

    

  


  

    

      
packages

      
First-party tools, one verb each

      

        Install them side by side and they compose — euglena apps run through
        the installed code interpreter. Click any command to copy it.
      

    

    

      

        

          
          code
        

        
The Code language toolchain — six value kinds, no type keywords, interpreter plus native/wasm compiler.

        
SDK tier by default (compiler included). Add --runtime for the smaller LLVM-free interpreter-only build, or --link to also get a bare code command (opt-in — it collides with VS Code's CLI).

        

          cdlvsm install code
          
        

      

      

        

          
          euglena
        

        
The euglena app CLI — scaffold, run, and build Euglena apps.

        
Runs apps through the code interpreter, so install both, then point euglena at it: euglena code set ~/.local/bin/cdlvsm-code.

        

          cdlvsm install euglena
          
        

      

    

  


  

    

      
usage

      
The whole surface area

      

        Five verbs and an escape hatch. Anything not reserved is treated as an
        installed package name and dispatched straight to its binary.
      

    

    

      

        
Commands

        

          
CommandWhat it does

          
            
cdlvsm install <pkg> [--runtime] [--link]Install a package from its latest release (or version pin)

            
cdlvsm upgrade [pkg]Update one package, or every installed one — reusing recorded settings

            
cdlvsm listShow installed packages, versions, and shims

            
cdlvsm uninstall <pkg>Remove a package and only the symlinks cdlvsm made

            
cdlvsm <pkg> <args…>Run an installed package's binary, transparently

          
        

      

      

        
Environment

        
    
          
  • PREFIX — install root (default $HOME/.local). Packages live under $PREFIX/share/cdlvsm/packages/; shims in $PREFIX/bin.
    • 
          
  • CDLVSM_CLI_VERSION — pin which cdlvsm build the installer script fetches (e.g. v0.2.2).
    • 
          
  • CDLVSM_CODE_VERSION / CDLVSM_EUGLENA_VERSION — pin a package's release instead of fetching the latest.
    • 
        

      

    

    

      

        
Install

        

          curl -sSf https://raw.githubusercontent.com/codelovesme/cdlvsm-cli/main/install.sh | sh
          
        

        
Linux x86_64, for now. Installs to ~/.local/bin — override with PREFIX=…. Building from source? Just cargo build --release; there are no system dependencies.
